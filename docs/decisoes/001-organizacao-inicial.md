# 001 — Organização inicial

Data: 06/11/2026. Estado: aceita para esta fundação documental.

## Contexto

O usuário solicitou preparar o repositório e estruturar a arquitetura antes da implementação. O ZIP recebido contém uma prática de antifraude, distinta do projeto de turnover.

## Alternativas

Adaptar diretamente o turnover; misturar imediatamente o scaffold com implementação; manter projeto separado e documentar antes de implementar.

## Decisão

Manter antifraude em repositório próprio. Preservar material textual e código originais para consulta em material/, sem dados brutos no Git. Registrar requisitos, pegadinhas e decisões separadamente. Usar template de PR e orientações para agentes.

## Evidência

Solicitação do usuário e leitura do README, demanda, notebook, contrato e código do ZIP cdd_pratica_mlops_parte1.zip.

## Consequências

O repositório começa com documentação e referência, sem modelo em produção. Dados permanecem no ZIP original. Arquitetura detalhada, algoritmo e threshold ainda exigem análise. O próximo passo é a auditoria do histórico.
